# Release Notes

## v0.4.0

This release focuses on improving how The Recursive Manifesto is presented and discovered across the web.

### Highlights
- Added richer page metadata for search engines and social sharing.
- Improved Open Graph and Twitter card support for better previews.
- Added structured data to help the manifesto appear more clearly in web results.
- Strengthened site identity with updated theme, manifest, and icon metadata.

### What Changed
- Expanded the page head metadata to include a clearer description and canonical URL.
- Added Open Graph and Twitter tags for improved sharing previews.
- Included schema.org metadata to describe the page and manifesto content.
- Refined web app metadata for better mobile and install experience.

### Notes
- The manifesto content itself remains the same; this release is primarily about presentation, discoverability, and sharing.
